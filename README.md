## ✨ Overview

NeuroTranslate is a production-ready, SaaS-grade language translation application built with a modern tech stack. It features a stunning glassmorphism landing page, fully responsive UI, and lightning-fast backend processing powered by advanced machine learning models (Deep Translator).

No API keys. Zero latency. Just seamless communication across 100+ languages natively.

## 🚀 Key Features

*   **Next-Gen UI/UX**: Premium Dark/Light mode, animated gradients, glassmorphism cards, and smooth scroll reveals.
*   **100+ Languages**: From English to Zulu, translate anything instantly with Auto-Detect functionality.
*   **Text-to-Speech (TTS)**: Listen to native pronunciation directly in your browser using Google TTS.
*   **Responsive Design**: Flawlessly adapts to any device, mobile or desktop.
*   **Developer Friendly**: Clean code structure with decoupled Flask backend and vanilla JS frontend.

## 🛠️ Technology Stack

*   **Frontend**: HTML5, Modern CSS3 (Variables, Animations, Flexbox/Grid), Vanilla JavaScript (ES6+).
*   **Backend**: Python 3.x, Flask (`app.py`).
*   **Core Logic**: `deep-translator` (Google Translate Engine under the hood, completely free).
*   **Audio**: `gTTS` (Google Text-to-Speech) natively encoded to Base64 to prevent storage clutter.

## 🖥️ Setup & Installation

Follow these steps to deploy NeuroTranslate locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/NeuroTranslate.git
    cd NeuroTranslate
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Flask application:**
    ```bash
    python app.py
    ```

4.  **Open in your browser:**
    Navigate to `http://127.0.0.1:5000` to start translating!
